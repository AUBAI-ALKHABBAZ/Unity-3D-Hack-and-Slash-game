# Unity-3D-Hack-and-Slash-game
Developed a fully functional 3D Hack and Slash game using the Unity Engine
The project demonstrates end-to-end game development, focusing on immersive gameplay mechanics, enemy AI, and smooth character animations. Built from the ground up and deployed for the web.

Key Technical Implementations:

• Player Mechanics: Implemented movement and combat using Character Controller and Animation BlendTrees.
• Camera System: Designed an advanced, dynamic camera follow system using Cinemachine.
• Enemy AI: Integrated NavMesh for intelligent enemy pathfinding and behavior.
• Visuals & Audio: Utilized Particle Systems for VFX and managed audio feedback.
• Deployment: Exported and published the final game build via WebGL.
